# Автоматизований ETL-конвеєр обробки даних Exceldiff

## 1. Призначення системи
Призначений для автоматизації процесів імпорту, нормалізації, диференціального аналізу та стилізованого вивантаження реєстрів. 
Об'єднує окремі етапи обробки в єдиний конвеєр за допомогою головного модуля (main.py)

## 2. Структура каталогів та артефактів
Exceldiff
├── input/                  # Вхідні дані (заповнюються користувачем)
│   ├── старий_файл.csv     # Історична база даних за попередній період
│   └── новий_файл.xlsx     # Свіжий масив даних для обробки
│
├── temp/                   # Тимчасові файли
│   ├── extracted_new.csv   # Проміжний масив після первинного імпорту
│   └── updated_new.csv     # Результат порівняння перед фінальним вивантаженням
│
├── output/                 # Вихідні результати
│   ├── FINAL_*.xlsx        # Форматований звіт із цільовим стилюванням
│   └── info.log            # Журнал аудиту та фіксації змін у даних
│
├── read_xlsx.py            # Модуль Кроку 1: Екстракція та очищення даних
├── compare_csv.py          # Модуль Кроку 2: Диференціальний аналіз та актуалізація
├── csv_to_xlsx.py          # Модуль Кроку 3: Рендеринг та форматування Excel
└── main.py                 # Головний оркестратор (єдина точка входу)

## 3. Системні залежності та налаштування середовища

Для ізоляції залежностей та коректного функціонування комплексу необхідне середовище Python версії 3.7+ та розгортання віртуального оточення.

### 3.1. Ініціалізація та активація віртуального середовища (venv)
Виконайте у терміналі з кореневої папки проєкту:

(Для Linux / macOS)
```bash
python3 -m venv venv
source venv/bin/activate
```
Для Windows (Command Prompt):
```DOS
python -m venv venv
call venv\Scripts\activate.cmd
```
Для Windows (PowerShell):
```PowerShell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

### 3.2. Встановлення пакетів
Після активації середовища виконайте оновлення менеджера пакетів та інсталяцію всіх необхідних бібліотек (включаючи openpyxl) за допомогою файлу маніфесту:

"""Bash
pip install --upgrade pip
pip install -r requirements.txt"""

## 4. Регламент запуску та використання
Підготовка даних: Розмістити в директорії input/ один файл історичних даних .csv та один свіжий звіт .xlsx.

Примітка: Переконайтеся, що папка не містить дублюючих файлів з однаковими розширеннями для запобігання колізій при автоматичному скануванні.

Виконання: Запустити головний сценарій через консоль з кореня проєкту:

Bash
python main.py
Контроль результатів: На виході в директорії output/ згенеруються два файли:

FINAL_<назва_файлу>.xlsx — підсумкова таблиця (заголовки розділів об'єднані, вирівняні по центру, виділені напівжирним шрифтом із жовтим фоном).

info.log — текстовий звіт про всі виявлені зміни, додавання або видалення записів.

## 5. Логіка функціонування конвеєра (main.py)
Ініціалізація: Скрипт автоматично перевіряє та створює структуру папок (input/, temp/, output/).

Сканування: Автоматично ідентифікує імена файлів у input/ та транслює їхні шляхи по ланцюжку функцій.

Крок 1 (read_xlsx.py): Зчитує новий Excel-файл, нормалізує дати та номери телефонів, маркує проблемні зони та зберігає CSV в temp/.

Крок 2 (compare_csv.py): Зіставляє проміжний CSV зі старою базою, відновлює відсутні атрибути та фіксує аномалії в output/info.log.

Крок 3 (csv_to_xlsx.py): Конвертує оновлений масив у фінальний XLSX-документ із застосуванням форматування.
